# Game GDD (Game Design Document)

**Game Name:** Lumi

**Genre:** 2D Platform / Puzzle

**Elevator Pitch:** Lumi is an innovative 2D platform-puzzle game where instead of controlling the character directly, the player shapes the environment to keep Lumi alive. As Lumi moves forward on its own, the player draws a safe path by placing platforms, bouncers, and shields at strategic points. The main objective is to safely guide Lumi to the end of the level by redirecting enemies and fending off hazards.

**Core Loop:** Analyze Threats -> Select Tool -> Place with Mouse -> Protect Lumi -> Reach the Goal.

**Controls:**
* **Keyboard (Tool Selection):**
  * `Z`: Platform
  * `X`: Redirect Enemy
  * `C`: Bouncer
  * `V`: Shield
* **Mouse:**
  * `Left Click`: Place the selected tool into the game world.

**Win-Lose Conditions:**
* **Win Condition:** Lumi successfully overcomes traps and enemies to reach the goal (exit door/flag) at the end of the level.
* **Lose Condition:** Lumi falls into the void, touches enemies, or hits obstacles, resulting in losing a life.

**Art Style:** Minimalist 2D / Vector Design (Dark space theme and flat color palette).
